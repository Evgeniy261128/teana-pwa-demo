# Магазин чая (Tea Shop PWA)

## Описание проекта
Проект объединяет в себе SEO-оптимизированный лендинг и Progressive Web App (PWA) для магазина редких сортов чая. Главная цель продукта — привлечение органического трафика из поисковиков и повышение возвращаемости клиентов за счет мотивации установить приложение на главный экран смартфона.

## Целевая аудитория и проблема
* **Аудитория:** Розничные покупатели (B2C), ценители чая.
* **Проблема:** Сложность запоминания любимых сортов, правил их заваривания и отсутствие быстрого доступа к магазину.
* **Решение:** Единая платформа, где главная страница продает идею и привлекает трафик, а внутреннее PWA-приложение дает удобный каталог, инструкции и разовую скидку за установку.

## Ключевые возможности (MVP)
* **SEO-лендинг:** Корневая страница (`/`) с рассказом о магазине, преимуществах продукта и призывом установить PWA.
* **PWA Навигация (Bottom Tab Bar):** 4 основных раздела приложения:
  1. **Каталог** — витрина товаров с детальными карточками (описание, цены, граммовки).
  2. **Рецепты** — инструкции по правильному завариванию разных видов чая.
  3. **Контакты** — интеграция Яндекс.Карт, адрес, режим работы и кликабельный телефон.
  4. **Профиль** — генерация уникального QR-кода на устройстве клиента для получения скидки.
* **Механика удержания (PWA):** Уникальный QR-код на устройстве клиента (без обязательной регистрации) для разовой скидки.
* **Панель продавца:** Скрытый раздел для продавца (сканирование QR-кода покупателя и валидация скидки через БД).
* **SEO:** Динамический рендеринг (SSR), автоматическая генерация мета-тегов и микроразметка Schema.org (Product, Article, LocalBusiness).

## Технологический стек
* **Frontend:** React / Next.js (App Router), Tailwind CSS.
* **Backend / Database:** Supabase (PostgreSQL).
* **PWA:** `next-pwa`.
* **Интеграции:** Яндекс.Карты (Yandex Maps API / iframe).

## Запуск проекта локально
1. Установите зависимости: `npm install`
2. Скопируйте `.env.example` в `.env.local` и укажите ключи Supabase:
   NEXT_PUBLIC_SUPABASE_URL=your-project-url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
3. Запустите сервер разработки: `npm run dev`
4. Откройте `http://localhost:3000`.

## Переменные окружения и Секреты
Все секреты (API ключи, сервисные роли БД) хранятся в `.env.local` и добавлены в `.gitignore`. Никогда не коммитьте боевые ключи в репозиторий.

## Правила работы с базой данных
Любое изменение структуры таблиц должно оформляться в виде SQL-файла в папке `supabase/migrations/`. Доступ к таблице заявок на скидку должен быть защищен через Row Level Security (RLS) — запись доступна анонимно, а чтение/изменение только администраторам.

## Статус проекта и План развития
* Текущий статус: **MVP (Разработка)**.
* В следующих релизах (V2): Корзина, онлайн-оплата, доставка, учет остатков, CRM.
